# Specification snapshots

Retrieved for the publishing architecture research on 2026-11-06. HTML files preserve upstream responses; text companions are searchable extracts, not normative replacements. Stylesheets and linked subpages are not bundled. Original licenses and attribution remain in each source.

Core = publishing/auth/interaction. Microformats = HTML vocabulary and parsing. Supporting = referenced standards and feed formats. Optional = features outside the initial publishing scope. These groups describe plan scope, not standards maturity.

The Micropub extensions page includes stable extensions, proposals, and brainstorming. JF2 and Post Type Discovery are W3C Notes; neither should be described as a W3C Recommendation. Microformats and IndieAuth are living specifications. RFCs are fixed documents; OAuth RFC 9700 updates security guidance for the older OAuth RFCs.
